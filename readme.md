
# Тестовое задание: семантические признаки музыкальных треков для рекомендательных систем

> Выполнение тестового задания не обязательно для участия в отборе на проект, но значительно повышает приоритет в рейтинге.

## Цель

Исследовать, какие семантические признаки музыкальных треков могут быть полезны для задач рекомендаций, и реализовать базовый пайплайн автоматического извлечения или предсказания таких признаков.

**Ожидаемый результат:** небольшой датасет музыкальных треков (50–100 объектов), обогащённый характеристиками (жанр, настроение, контекст использования и др.), а также анализ полезности этих признаков для рекомендательных систем.

---

## Задание 1. Сбор датасета

Собрать небольшой датасет из **50–100 музыкальных треков**.

### Возможные источники

- YouTube
- Spotify Previews
- Kaggle
- Hugging Face Datasets
- Другие открытые источники

### Данные по каждому треку

Желательно собрать:

- Название трека
- Исполнителя
- Ссылку на аудио или аудиофрагмент
- Базовые метаданные (при наличии)

### Что необходимо описать

1. Использованные источники данных.
2. Принцип отбора треков.
3. Жанры и категории, представленные в датасете.
4. Ограничения на количество треков одного жанра или исполнителя.

---

## Задание 2. Формирование набора признаков

Определить набор **семантических признаков**, которыми можно обогатить музыкальные треки.

### Примеры признаков

| Признак | Примеры значений |
|---|---|
| Жанр | Rock, Pop, Jazz, Electronic |
| Настроение | Energetic, Calm, Sad, Happy |
| Темп / энергичность | Low, Medium, High |
| Контекст использования | Work, Workout, Party, Relax |
| Атмосфера | Atmospheric, Dark, Romantic |
| Эпоха | 1980s, 1990s, 2000s, 2010s |
| Похожие артисты | Список исполнителей |

### Возможные подходы

- Автоматическое извлечение признаков
- Предобученные модели
- LLM
- Аудиомодели (CLAP, MusicLM-подобные модели, Open Audio Embeddings)

### Что необходимо описать

1. Выбранный набор признаков.
2. Обоснование полезности каждого признака для музыкальных рекомендаций.

---

## Задание 3. Извлечение признаков

Реализовать пайплайн автоматического извлечения или предсказания выбранных признаков.

### Возможные методы

- Audio Embeddings
- Audio Classification Models
- Large Language Models (LLM)
- Multimodal Models

### Что необходимо описать

1. Использованные модели и библиотеки.
2. Причины выбора конкретного подхода.
3. Рассмотренные альтернативы и их преимущества или недостатки.

---

## Задание 4. Разведочный анализ данных (EDA)

Провести анализ полученного датасета.

### Обязательные направления анализа

- Распределение жанров
- Распределение настроений
- Распределение контекстов использования
- Корреляции между признаками (при наличии)

### Визуализации

Построить несколько графиков, иллюстрирующих распределения и взаимосвязи характеристик музыкальных треков.

---

## Задание 5. Эксперименты с представлением треков

На основе извлечённых признаков или эмбеддингов исследовать семантическую похожесть музыкальных треков.

### Эксперименты

1. Реализовать простую модель поиска похожих треков.
2. Визуализировать пространство эмбеддингов с помощью UMAP или t-SNE.
3. Продемонстрировать примеры ближайших соседей для нескольких треков.

### Что необходимо проанализировать

- Насколько полученные признаки отражают реальную музыкальную похожесть.
- Какие признаки оказались наиболее информативными.
- Какие ограничения имеет построенный подход.

---

## Требования к документации

В ноутбуке необходимо подробно описать:

1. Процесс сбора датасета.
2. Выбранные признаки и обоснование их использования.
3. Модели и методы извлечения признаков.
4. Проведённые эксперименты.
5. Результаты анализа и выводы для задач музыкальных рекомендаций.
6. Обнаруженные проблемы и ограничения.
